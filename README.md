# 🎬 Splitora Desktop

نسخة الديسك توب من **Splitora** — أداة تقسيم الفيديوهات الاحترافية.

- ⚡ محرك FFmpeg **الأصلي** مدمج داخل البرنامج — أسرع 5-10 مرات من نسخة المتصفح
- 📦 **بدون أي تحميل إضافي** — كل حاجة جوه البرنامج
- 🌐 يشتغل **بدون إنترنت** تماماً
- 🎬 أي حجم فيديو — حتى عشرات الجيجا
- 🔒 ملفاتك لا تغادر جهازك أبداً
- 📱 دعم تحويل الريلز (9:16) وخيارات الجودة (أصلية / 1080p / 720p)
- 🔗 **تحميل من الروابط**: يوتيوب وتيك توك وأكثر من 1800 موقع (بمحرك yt-dlp المدمج الذي يحدّث نفسه تلقائياً)
- 📝 **نص فوق الفيديو** بأربعة أشكال (أبيض بظل / أصفر بحدود / شريط داكن / كبسولة ملونة) وثلاثة مواضع، مع معاينة حية
- 🎯 **مقاطع مخصصة**: تحديد من ثانية إلى ثانية (مثال 1:02 ← 1:15) لعدة مقاطع دفعة واحدة
- 🎞️ **تحديد الفريم ريت**: الأصلي / 24 / 30 / 60
- 🖼️ **ثامنيل مدمج**: صورة غلاف تُدمج داخل كل مقطع
- 🔑 **فترة تجريبية 7 أيام** بكل الميزات (بعلامة Splitora المائية على الفيديوهات)، وتفعيل باشتراك شهري/سنوي/مدى الحياة بدون علامة مائية
- 🇪🇬 عربي RTL + English

---

## 🧪 تشغيل نسخة التطوير محلياً (اختياري)

لو عايزة تجربي قبل البناء (محتاج Node.js 18+):

```bash
cd splitora-desktop
npm install
npm start
```

## 🔑 نظام التراخيص (للمالكة فقط)

البرنامج بيبدأ بفترة تجريبية 7 أيام تلقائياً لأي مستخدم جديد (كل الميزات شغالة، لكن الفيديوهات المُصدَّرة عليها علامة Splitora المائية الصغيرة). بعد انتهاء الـ7 أيام، لازم مفتاح تفعيل صحيح عشان يكمل التصدير.

**توليد مفتاح لعميل جديد — طريقة 1: لوحة تحكم بصرية (الأسهل)**

```bash
npm run panel
```

هيفتحلك المتصفح تلقائياً على لوحة تحكم فيها فورم بسيط (اسم العميل + نوع الباقة) وزرار "توليد المفتاح"، وجدول بيسجّل كل المفاتيح اللي طلعتيها قبل كده مع تاريخ الانتهاء وحالة كل مفتاح (نشط / منتهي). كل حاجة شغالة محلياً على جهازك بس (`localhost`) — مفيش أي بيانات بتترفع لأي سيرفر خارجي.

**طريقة 2: من الترمينال**

```bash
node scripts/keygen.js monthly              # اشتراك شهري
node scripts/keygen.js yearly "اسم العميل"   # اشتراك سنوي
node scripts/keygen.js lifetime              # مدى الحياة
```

**في الحالتين:** المفتاح الناتج تبعتيه للعميل، وهو يلزقه في شاشة "تفعيل الاشتراك" جوه البرنامج.

⚠️ **مهم:** الطريقتين محتاجين ملف `scripts/private-key.pem` (اتبعتلك مرة واحدة بشكل منفصل، مش موجود في المستودع خالص لأسباب أمان). حطيه في مجلد `scripts/` على جهازك بس، ومتشاركيهوش مع حد ولا ترفعيه لأي مكان — أي حد يوصله يقدر يصنع مفاتيح تفعيل وهمية لبرنامجك.

**حدود النظام الحالي (بدون سيرفر):** التحقق كله بيحصل محلياً على جهاز العميل، فمفيش طريقة تلغي مفتاح اتفعّل قبل كده أو توقفي مشاركته بين ناس. لو احتجتي تحكم أدق مستقبلاً (سيرفر تحقق دوري، تحديد عدد الأجهزة لكل مفتاح)، ده تطوير منفصل ممكن نضيفه بعدين.

## 🛠️ ملاحظات تقنية

| البند | التفاصيل |
|---|---|
| الواجهة | Electron + نفس واجهة Splitora الويب (عربي RTL) |
| المعالجة | FFmpeg أصلي عبر `ffmpeg-static` + `ffprobe-static` |
| التقسيم | أمر segment واحد للفيديو كله — أقصى سرعة |
| تحذير Windows | أول تشغيل هيظهر تحذير SmartScreen لأن البرنامج غير موقّع رقمياً (التوقيع بفلوس) — اضغطي **More info ← Run anyway**. ده طبيعي لكل البرامج المجانية غير الموقعة |
| تحميل الروابط | yt-dlp يُحمَّل تلقائياً أثناء البناء على GitHub (خطوة جاهزة في الـ workflow) ويحدّث نفسه عند تشغيل البرنامج |
| ملاحظة يوتيوب | نادراً قد يطلب يوتيوب تحققاً إضافياً من بعض الشبكات — البرنامج يعرض رسالة واضحة ويكفي إعادة المحاولة لاحقاً |
| حجم البرنامج | ~110-130 ميجا (Electron + FFmpeg + yt-dlp مدمجين) |
